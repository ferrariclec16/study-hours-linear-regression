# 공부 시간에 따른 시험 점수 예측

## 실행 결과가 포함된 노트북

**[노트북 보기: 설명·코드·표·그래프](AI_Linear_Regression_Study_Scores.ipynb)**

[Google Colab에서 실행](https://colab.research.google.com/github/ferrariclec16/study-hours-linear-regression/blob/main/AI_Linear_Regression_Study_Scores.ipynb)

노트북에는 데이터가 포함되어 있어 CSV를 별도로 받지 않고도 실행할 수 있습니다.

공부 시간을 입력하면 시험 점수를 예측하는 초보자용 단순 선형 회귀 프로젝트입니다.
Python 3.10 이상을 사용하세요.

## 데이터

`study_scores.csv`에는 **실제 조사 자료가 아닌 학습용 가상 데이터 100개**가 있습니다.
한 행은 가상의 학생 한 명입니다.

| 열 | 의미 | 단위 |
|---|---|---|
| study_hours | 시험 전 1주일의 하루 평균 공부 시간 | 시간/일 |
| exam_score | 시험 점수 | 점, 0~100 |

`generate_data.py`에서 난수 시드 42를 사용해 생성했습니다. 점수는
`30 + 7 × 공부 시간 + 무작위 오차`로 만들고 0~100 범위로 제한했습니다.
처음부터 선형 관계를 넣었기 때문에 좋은 성능이 나와도 실제 교육 현장에서의 예측력을 입증하지 않습니다.

## 실행

터미널에서 이 프로젝트 폴더로 이동한 뒤 실행하세요.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

기본값은 하루 평균 5시간입니다. 다른 시간으로 예측하려면:

```bash
python main.py --hours 6.5
```

데이터 파일은 이미 포함되어 있습니다. 같은 데이터를 재생성하려면
`python generate_data.py`를 실행하세요. 기존 데이터 파일을 덮어씁니다.

## 코드 흐름과 결과

1. CSV를 읽고 입력 X와 목표 y를 분리합니다.
2. 무작위로 학습용 80개, 테스트용 20개를 분리합니다.
3. 학습 데이터만으로 `LinearRegression`을 학습합니다.
4. 테스트 데이터에서 MAE, RMSE, R²를 계산합니다.
5. 학습 데이터 평균만 예측하는 기준 모델과 MAE를 비교합니다.
6. 입력 시간에 대한 예측과 회귀선 그래프를 저장합니다.

실행할 때마다 `outputs` 폴더의 아래 파일이 갱신됩니다.

- `results.txt`: 회귀식, 성능 지표, 입력 시간의 예측 점수
- `test_predictions.csv`: 테스트 데이터의 실제 점수, 예측 점수, 절대 오차
- `regression_plot.png`: 학습·테스트 데이터 산점도와 회귀선

MAE는 평균적으로 몇 점 틀렸는지 나타내며 낮을수록 좋습니다.
RMSE도 점 단위이며 큰 오차에 더 민감합니다.
R²는 1에 가까울수록 좋고 0 이하가 될 수도 있습니다.
